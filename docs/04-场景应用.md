# 场景应用:同一套引擎,喂不同 agent

> 编译知识库的价值不在「读笔记」,在于给**所有需要私有上下文的 agent** 当外脑——AI coding、agent 交易、个人学习、办公知识管理,都是同一套引擎的实例:raw 里放你的私有资料 → 编译成手册 → 通过 MCP 喂给干活的 agent。

## 通用骨架(每个场景都是这个闭环)

```
场景的 raw/         场景的 wiki/            场景的 agent
文章/复盘/规范   →  编译成手册(概念/矛盾/置信度)  →  MCP 注入 → 干活
    ↑                                                   │
    └──── 踩坑/新发现 observe 回灌 ◄─── 执行中的失败 ◄──┘
```

---

## 场景 1:A I 编程(喂 Claude Code / Codex)

**典型用户**:一个人或小团队维护生产代码库的工程师。

**raw/ 放什么**(私有知识,模型肚子里没有):
- 线上事故复盘(「支付超时根因是 X,上次修法是 Y」)
- 架构决策记录(为什么用这个中间件)
- 代码库规范(命名、目录、错误处理约定)
- API 契约、踩坑规则(「改这个模块会碰别的」)

**怎么用**:
```bash
./kcp compile raw/事故复盘-支付超时.md   # 编译成手册页
# 在 Claude Code/Codex 的 .mcp.json 接上(见 context/.mcp.json.example)
# 它写代码时自动 search_wiki → 命中「支付超时复盘」→ 不重犯历史错误
```

**复利长什么样**:每次线上事故 `observe` → 编译回灌 → 手册更密 → 下次 agent 直接带坑工作。

---

## 场景 2:Agent 交易(喂交易 agent)

**典型用户**:写策略、跑回测、用 agent 做研究的量化交易者。

**raw/ 放什么**:
- 策略规则与边界(「只在 X 条件下开仓」「回撤 > 5% 必须降杠杆」)
- 历史失败案例(亏损复盘:那次为什么亏)
- 风控规则、市场经验、数据字典(字段含义)

**怎么用**:
```bash
./kcp compile raw/亏损复盘-2024-05.md
# 交易 agent 通过 MCP 查 search_wiki → 拿到策略边界 + 失败案例 → 决策更稳
```

**复利长什么样**:亏损/异常先 `observe`,编译回灌成「我的实践」——你的交易 agent 是唯一一个「记得你所有亏钱教训」的 agent。

## 场景 3:个人学习(课程/论文/剪藏)

**典型用户**:读课程、论文、公众号,想让知识沉淀成自己的体系。

**raw/ 放什么**:
- 课程讲义、论文、Web 剪藏(`raw/` 支持 .md/.txt;PDF 先 `scripts/pdf2md.sh` 转)
- 自己的读书笔记、想法

**怎么用**:
```bash
./kcp compile raw/M07-记忆系统与AgenticRAG.md
./kcp query "记忆系统四分类和上下文工程怎么对接?"   # 跨页综合 + 建议 filed back
```

**复利长什么样**:每个源编译时交叉引用 5-15 个已有页——**知识不是堆积,是连网**;每问一个好问题,filed back 成 synthesis,体系越来越密。`kcp eval` 还可以验证「编译 vs 原文检索」在你自己的学习材料上哪个更强。

---

## 场景 4:办公/知识工作者(喂个人助理)

**典型用户**:要处理大量内部文档、制度、复盘的知识工作者。

**raw/ 放什么**:
- 会议纪要、项目复盘、制度文档、SOP
- 供应商/客户沟通沉淀、历史决策

**怎么用**:
```bash
./kcp compile raw/项目复盘-Q3.md
# 个人助理 agent(Claude Code/自研)通过 MCP 查 search_wiki →
# 「这个项目以前踩过什么坑?上次是怎么处理的?」——第一次就站在全公司历史肩膀上
```

**复利长什么样**:组织知识从「存在某个人的硬盘/某次会议纪要里」变成「可检索、可交叉引用、带矛盾标注的资产」——人走了知识留下,新人 10 分钟上手。

---

## 各场景对照速查

| 场景 | raw 放什么 | 喂给谁 | 复利标志 |
|---|---|---|---|
| AI 编程 | 事故复盘/架构决策/规范/踩坑 | Claude Code / Codex | 历史事故不再重犯 |
| Agent 交易 | 策略边界/亏损复盘/风控规则 | 交易 agent | 每个亏钱教训都被记住 |
| 个人学习 | 课程/论文/剪藏 | kcp query 自己 | 知识连网 + filed back 沉淀 |
| 办公 | 纪要/复盘/制度/SOP | 个人助理 agent | 组织知识不随人走 |

## 开始用

各场景命令都是同一条闭环;配 key 与完整的 `compile → query → observe` 流程见 `01-上手.md`。

**核心纪律**:先跑通一个小闭环(1 个源 → 编译 → 喂 agent),再扩——复利从第一笔开始。
