# 隐私模型

你的知识库是**私有资产**,但你要能把它导出、分享、甚至开放给 agent。本项目用三层机制在"保留完整版"和"可导出公开版"之间分层。

## 1. 页面级排除

frontmatter 加 `public: false`,整页不进公开版:

```yaml
---
type: source
public: false
---
```

适用于:含交易策略、亏损明细、个人判断的整页。

## 2. 段落级标记

用 HTML 注释标记私密段落,导出时自动剥离:

```markdown
<!-- PRIVATE -->
这段内容只在完整版中可见(比如具体仓位、真实亏损数字)
<!-- /PRIVATE -->
```

适用于:一页里少数私密段落,其余可公开。

## 3. 替换规则(导出脚本自动执行)

| 原内容 | 公开版替换为 |
|---|---|
| 具体薪资数字 | [薪资信息] |
| 股权比例 | [股权信息] |
| 本地文件路径 | [本地路径] |

> 按你的隐私需求自定义 `scripts/export-public.sh` 里的替换规则。

## 导出

```bash
bash scripts/export-public.sh   # 输出到 wiki-public/,可直接部署/分享
```

## 边界原则

- **开源的是方法论,不是你的知识**:`raw/` 与 `wiki/` 被 `.gitignore` 排除,不进开源仓库
- **知识库属于用户**:git 天然版本历史,可随时导出带走——可移植性是信任前提
- **给 agent 用不等于公开**:支柱 B 的 MCP server 默认只在本机运行,暴露的是你自己 wiki 的只读接口;开放给别人调用时,用 A2A 的服务端加认证与 AgentCard security 声明,而不是直接暴露 MCP
